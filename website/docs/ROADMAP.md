# Roadmap

## Phase 1 - Foundation

- Initialize Next.js with TypeScript, App Router, Tailwind CSS, ESLint, and import aliases.
- Prepare shadcn/ui-compatible configuration.
- Add MDX foundation.
- Add OpenNext for Cloudflare, Wrangler, and Cloudflare deployment configuration.
- Add VS Code workspace recommendations.

## Phase 2 - Project Architecture and Design System

- Define application architecture, rendering strategy, data flow, and component hierarchy.
- Define design tokens for typography, spacing, color, radius, shadows, breakpoints, and accessibility.
- Define reusable UI component architecture.
- Define navigation, SEO, performance, and security strategies.
- Document Cloudflare-first engineering rules.

## Phase 3 - Core Layout and Navigation

- Build site shell, navbar, footer, theme switch, breadcrumbs, and base page layout.
- Add accessible loading, error, empty, and not-found states.
- Implement initial route structure without full content depth.

## Phase 4 - Content Engine

- Implement MDX collections for blog, learning notes, projects, and resources.
- Add typed metadata, article layouts, indexes, tags, categories, and pagination.
- Add RSS feed and content preview components.

## Phase 5 - SEO and Analytics

- Implement dynamic sitemap, robots, canonical metadata, JSON-LD, Open Graph, Twitter Cards, and breadcrumbs.
- Add Cloudflare Web Analytics and Google Analytics.
- Connect Google Search Console.

## Phase 6 - Growth and Monetization

- Add newsletter capture, lead magnets, contact workflows, service pages, and conversion tracking.
- Add privacy and terms pages.
- Evaluate Turnstile, email provider integration, and analytics events.

## Phase 7 - Scaling and Future Products

- Add Cloudflare D1, R2, KV, and Cache API integrations when needed.
- Add search architecture suitable for large archives.
- Add authentication with Better Auth only if future SaaS or gated products require it.
- Add observability, performance budgets, and automated quality checks.
